# Sistema Inteligente de Descarga VLI

Este projeto é um sistema web para controle e registro de operações de descarga de vagões, desenvolvido para facilitar a gestão, acompanhamento e geração de relatórios das operações em moegas.

## Funcionalidades principais
- Registro de composições e posicionamentos de vagões
- Cronometragem automática de puxada e descarga
- Exportação de relatórios em PDF e compartilhamento via WhatsApp
- Visualização de histórico e desempenho
- Interface moderna, responsiva e fácil de usar
- Integração com Firebase Firestore para armazenamento dos dados

## Como rodar localmente
1. Clone este repositório:
   ```bash
   git clone https://github.com/elvisdemarco-vli/sistema-vli-descarga.git
   ```
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Configure o Firebase em `src/firebaseConfig.js` (caso queira usar seu próprio projeto Firebase).
4. Rode o sistema:
   ```bash
   npm start
   ```
5. Acesse em [http://localhost:3000](http://localhost:3000)
